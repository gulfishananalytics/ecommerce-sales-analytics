# E-Commerce Sales Analytics

## Project Overview

This project analyzes e-commerce sales data to understand revenue, profitability, customer behavior, product performance, returns, and delivery performance.

The project demonstrates practical data analysis using PostgreSQL and Power BI, with a focus on business-oriented insights and decision-making.

## Tools & Technologies

- PostgreSQL
- SQL
- Power BI
- DAX
- Power Query

## Dataset

The project contains the following datasets:

- Customers
- Orders
- Products
- Returns
- Delivery

## Key Business Areas

The analysis covers:

- Total Revenue
- Total Profit
- Total Orders
- Average Order Value
- Monthly Revenue & Growth
- Product Performance
- Category Performance
- City-wise Revenue
- Customer Analysis
- Return Analysis
- Delivery Analysis
- Profitability Analysis
- Customer Purchase Behavior

## SQL Analysis

PostgreSQL was used to perform business analysis using:

- Joins
- GROUP BY & HAVING
- CASE WHEN
- CTEs
- Subqueries
- Window Functions
- LAG & LEAD
- Ranking
- Running Totals
- Moving Averages
- Date & Time Analysis
- Aggregations
- Return & Customer Analysis

## Power BI Dashboard

The Power BI dashboard provides an interactive view of sales performance through:

- Product Performance
- Customer Analysis

- Drill-down Analysis

## Key Objective

The objective of this project is to transform raw e-commerce data into meaningful business insights that can help understand sales performance, profitability, customer behavior, returns, and operational performance.
